---

### 🍪 Cookies e Sessions (ACT-PHP-002)

Nesta atividade, foram aplicados conceitos importantes como:

- `setcookie()` → criação de cookies  
- `$_COOKIE` → leitura de cookies  
- `session_start()` → início de sessão  
- `$_SESSION` → armazenamento de dados no servidor  
- `session_destroy()` → encerramento de sessão

---
